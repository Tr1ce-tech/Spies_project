# Предварительные связи Excel ↔ CSV

Исправный архив Excel повторно обработан и проверен. `link_excel_csv.py` ищет только кандидатов наблюдений по точному сочетанию номера билета, даты и номера рейса. Это не алгоритм объединения людей.

Запуск из корня проекта в новую папку:

```bash
.venv/bin/python pipelines/link_excel_csv.py --output proceed_data/excel_csv_next
.venv/bin/python -m unittest discover -s pipelines -v
```

Результат текущего запуска — `proceed_data/excel_csv_v1/`:

- `excel_csv_candidates.parquet`: ID обеих исходных записей, ID связи, основания проверки, число наблюдений/документов/маршрутов в блоке, наличие документа в записи CSV и версия правила.
- `manifest.json`: хэши входных Parquet и архива, объёмы и ограничения запуска. Персональные значения в сводку не включены.

Из 615 771 строки Excel и 155 147 строк CSV найдены 24 387 пар. В этом наборе каждая пара имеет уникальный ключ с обеих сторон. Из них в 14 460 совпадает набор слов имени и фамилии, но полное имя с отчеством не подтверждено. В остальных 9 927 состав полного имени не согласован. В 12 118 парах различаются известные коды бронирования; эта причина может пересекаться с причинами по имени. Различие PNR требует разбирательства и само по себе не доказывает разных людей.

Все 24 387 пар оставлены в `review`. Имена сравниваются после NFC, приведения регистра и пробелов: полный набор слов независимо от порядка. Транслитерация, сокращения и дописывание отсутствующих частей имени не выполняются. Совпадение только имени и фамилии сохраняется как частичное основание. Конфликтующие документы/маршруты внутри блока, несколько записей с одной стороны и разные известные времена также удерживаются для проверки.

В Excel нет паспортного поля. Ссылки на CSV позволяют просмотреть документ исходной записи, но документ не присваивается автоматически пассажиру Excel. Первичные записи не объединяются и не удаляются. Цепочек связей и групп людей этот этап не создаёт. Сведения о поездке не считаются доказательством совершённого перелёта.

Независимых истинных соответствий нет: precision и recall не рассчитаны. Не найденные по точному билету/дате/рейсу пары не исследованы; это не оценка полноты сопоставления. Дальнейший шаг — ручной разбор образцов с частичным совпадением имени и различиями PNR, затем расширение правил на другие источники.
