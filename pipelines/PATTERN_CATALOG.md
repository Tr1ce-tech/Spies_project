# Каталог профилей по пяти правилам

```bash
.venv/bin/python -m pipelines.build_pattern_catalog
.venv/bin/python -m unittest pipelines.test_pattern_catalog -v
node pipelines/test_pattern_catalog.mjs
```

Результат: `proceed_data/pattern_catalog_v1/index.html`. Открыть файл локально.
Существующая папка не перезаписывается; `--output` задаёт новый путь.
HTML самодостаточен, не обращается к внешним сервисам и содержит имена из
нормализованных профилей. Не публиковать его вместе с публичным кодом.

Отбор использует baseline_reasons, а не iforest_score или iforest_flag.
Каждый из пяти флагов заново сверяется с числовыми признаками и порогом когорты.
В файл попадают все соответствующие единицы, без усечения по числу результатов.
Локальные профили и предварительные группы — пересекающиеся представления,
не независимые люди. Модель и правила сопоставления не переобучаются.

В интерфейсе есть поиск по исходным вариантам имени и ID, выбор признаков,
условия «любой»/«все», сортировка показателей и страницы по 50 записей.
Детали содержат численные значения и пороги, все блоки дата/рейс и направления.
Доли повторения и редких направлений имеют явные знаменатели. Варианты имён
внутри группы сохраняются по источникам; удобное имя не выбирается автоматически.

Экспорт JSON включает весь результат фильтра. Основные таблицы:

- catalog.parquet — все отобранные профили/группы и признаки, без оценок модели;
- names.parquet — варианты имён, source_record_id, локаторы, SHA-256 и версии;
- flight_day_bins.parquet — все измеряемые блоки;
- routes.parquet — направления и их представленность в сопоставимой когорте;
- observation_members.parquet — полная связь со всеми первичными наблюдениями;
- catalog.json — облегчённые данные интерфейса. Полные связи наблюдений остаются
  в Parquet, чтобы не раздувать страницу повторяющимися идентификаторами;
- manifest.json, verification.json — происхождение и контроль полноты.

Пороговые правила наследуются из profile_patterns_v1. Кандидаты ограничены
условиями достаточности данных этого исследования; отсутствие в каталоге не
доказывает обычное поведение. Полный массив единиц — profile_scores.parquet.
Совпадение всех пяти правил в текущем массиве невозможно: сильное повторение
по критерию ≥5 блоков одного направления и доле ≥80% не встретилось.

Проверки Node выполняются на изолированной модели DOM без браузера: логика
фильтров, поиск, детализация и полный экспорт. Они не подтверждают визуальную
работу конкретного браузера. Персональные значения остаются в proceed_data,
исключённой из Git.
