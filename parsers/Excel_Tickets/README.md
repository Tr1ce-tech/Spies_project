# Excel-билеты в Parquet

Самостоятельная поставка для учебного проекта Catch The Spies. Вход — архив
`YourBoardingPassDotAero.zip`. Выход — **одна таблица `result/tickets.parquet`**:
один лист Excel соответствует одной строке. Повторяющиеся билеты не удаляются.


## Содержимое

- `parse_excel_tickets.py` — полный парсер; не импортирует основной проект.
- `verify_tickets.py` — проверка всех строк Parquet и независимое чтение образцов Excel.
- `test_parser.py` — тесты на синтетических данных.
- `requirements.txt` — две зависимости с зафиксированными версиями.
- `result/tickets.parquet` — готовая таблица.
- `result/tickets.manifest.json` — SHA-256 архива и книг, число листов, статусы, ошибки и время.
- `result/tickets.fields.json` — схема Parquet и соответствие полей ячейкам.
- `result/tickets.verification.json` — результат обратного чтения и сверки с openpyxl.
- `VALIDATION.md` — краткая сводка выполненного полного запуска.
- `logs/` — вывод тестов, полного парсинга и проверки.
- `checksums.json` — контрольные суммы файлов поставки.

Исправный исходник находится в raw_data; проверка описана в CURRENT_AUDIT.md. Служебные файлы macOS не считаются книгами.

## Установка и запуск

Проверено на Python 3.13. Для нового окружения в Linux/WSL:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest -v test_parser
python parse_excel_tickets.py /путь/к/YourBoardingPassDotAero.zip --output new_result/tickets.parquet
python verify_tickets.py /путь/к/YourBoardingPassDotAero.zip new_result/tickets.parquet
```

В Windows создайте окружение командой `py -3.13 -m venv .venv`, активируйте
`.venv\Scripts\Activate.ps1`; остальные команды аналогичны. Для проверки готовой
таблицы замените `new_result/tickets.parquet` на `result/tickets.parquet`.

Для короткого пробного запуска добавьте `--max-books 1`. Такой запуск явно
помечается `limited_run: true`, `complete: false`. Новую обработку запускайте
в новый путь: существующие результаты скрипт не перезаписывает.

## Поля

| Поле | Ячейка Excel | Значение |
|---|---|---|
| `passenger_title` | A3 | Обращение из билета; не используется для вывода пола |
| `passenger_name` | B3 | Имя пассажира |
| `loyalty_card` | F3 | Карта программы лояльности как единая исходная строка |
| `travel_class` | H3 | Класс обслуживания |
| `flight_number` | A5 | Обозначение рейса |
| `origin_city`, `destination_city` | D5, H5 | Названия городов |
| `gate` | B7 | Выход на посадку |
| `origin_airport`, `destination_airport` | D7, H7 | Коды аэропортов из источника |
| `departure_date` | A9 | Дата вылета, тип Parquet `date32` |
| `departure_time` | C9 | Локальное время HH:MM, без назначения часового пояса |
| `operator_text` | E9 | Исходный текст об операторе |
| `boarding_note` | A11 | Примечание о посадке |
| `seat` | H11 | Место |
| `booking_reference` | B13 | Код бронирования |
| `ticket_number` | E13 | Номер электронного билета, **строка** |
| `sequence_number` | H1 | Порядковый номер из посадочного талона, строка |

Для каждого поля выше сохранена отдельная колонка `имя_поля_raw` с исходным
текстом ячейки. Времена, номера билетов, карты, PNR и коды сохраняются строками;
начальные нули не удаляются.

Происхождение: `source_archive`, `source_archive_sha256`, `source_file`,
`source_file_sha256`, `source_sheet`, `source_sheet_index` (начиная с 1),
`source_sheet_xml`, `record_id`, `rule_version`. `record_id` — SHA-256 от
контрольной суммы архива, имени книги, имени и индекса листа. Это ID исходного
наблюдения, а не человека или уникального перелёта.

`raw_cells_json` хранит значения **всех** ячеек, включая подписи и явно пустые
ячейки; `cell_types_json` — их исходные OOXML-типы; `formulas_json` — формулы,
если они встретятся. Отсутствующая ячейка не имеет ключа. `field_status_json`
содержит статус каждого извлечённого поля. Правила и координаты закреплены в
`FIELDS`, `VERSION` и `tickets.fields.json`.

## Правила проверки

- Шаблон проверяется по A1=`BOARDING PASS`, A13=`PNR:`, D13=`E-TICKET`.
  На неподдерживаемом листе сырые ячейки остаются, нормализованные поля не угадываются.
- Даты принимаются только в явно указанном ISO-формате `YYYY-MM-DD` и
  проверяются по календарю. `03/02/2017` не интерпретируется автоматически.
- `null`, пустая строка и строковый маркер `N/A` различимы по исходному
  значению и статусу. Строковые маркеры: N/A, NA, NULL, NONE, NAN, «-».
- Числовые ячейки с идентификаторами не дополняются нулями и не объявляются
  надёжными строковыми ID: исходное число сохраняется в `_raw`, нормализованное
  значение остаётся пустым со статусом `nontext_value_not_inferred`.
- Формулы сохраняются, но не вычисляются; их кэш не считается проверенным значением.
- Коды аэропортов проверяются только по синтаксису. Например, исходный `REA`
  остаётся `REA`: это не подтверждение соответствия городу из соседней ячейки.
- Текст об операторе сохраняется без восстановления фактического перевозчика
  или codeshare. Дата и билет не доказывают состоявшийся перелёт.
- Ошибки листов сохраняются отдельными строками `needs_review`; ошибки книг
  отражаются в манифесте. Проблемный запуск возвращает ненулевой код и не
  получает `complete: true`. Состояние полей с пропусками — отдельная проверка.

## Что проверяется после записи

Весь Parquet читается пакетами: проверяются число строк, пофайловое число
листов, уникальность имён листов внутри книги, происхождение и ID, типы,
все связи `_raw` с исходными ячейками, даты и начальные нули. SHA-256 входа
повторно проверяется после запуска. Книги обходятся в сортированном порядке,
листы — в порядке `workbook.xml`, включая скрытые листы.

Дополнительно `openpyxl` независимо открывает первый, средний и последний
листы первой, средней и последней книги, а также образцы начальных нулей,
пропусков и Unicode-имён, если они встретились. Сверяются все заполненные
ячейки и именованные поля. Это выборочная сверка с источником, а не второе
полное чтение всех Excel-листов независимым парсером.

Пример чтения без дополнительных библиотек:

```python
import pyarrow.parquet as pq

table = pq.read_table(
    "result/tickets.parquet",
    columns=[
        "source_file",
        "source_sheet",
        "passenger_name",
        "departure_date",
        "flight_number",
        "origin_airport",
        "destination_airport",
        "ticket_number",
    ],
)
print(table.slice(0, 5).to_pylist())
```
