# Pointz XML

`parse_ds_parquet.py` строго читает `raw_data/PointzAggregator-AirlinesData.xml`. Повреждённый XML не восстанавливается молча. Исходные uid и номера карт остаются строками.

Из корня проекта:

```bash
.venv/bin/python parsers/XML_Parser/parse_ds_parquet.py
.venv/bin/python parsers/XML_Parser/verify_xml.py
.venv/bin/python -m unittest discover -s parsers/XML_Parser -p test_parser.py -v
```

Повторный запуск: `--output parsers/XML_Parser/result_new`. Существующая папка результата не перезаписывается; незавершённый проход остаётся в `.partial`.

В `result/` находятся три таблицы:

| Таблица | Единица | Строк |
|---|---|---:|
| users.parquet | Исходная пользовательская запись, включая пользователей без карт | 66 657 |
| cards.parquet | Карта источника, включая карты без операций | 88 818 |
| activities.parquet | Операция карты, не доказанный перелёт | 436 090 |

Связи: `user_record_id` и `card_record_id`. ID строятся из хэша источника и индексированного XML-локатора; не являются ID установленных людей. Пользователей без карт — 9 438, карт без операций — 645. Пустые карты не создают строки перелётов.

Происхождение: `source_file`, `source_sha256`, `rule_version`, `source_locator`. В users сохраняются все исходные атрибуты и `raw_user_xml`; это сериализация разобранного XML, а не точная байтовая копия. Исходные байты остаются в неизменённом raw_data. В activities есть исходные `*_raw`, нормализованная дата ISO date32 и `field_status_json`. Коды аэропортов и перевозчик не восстанавливаются по внешним справочникам.

`verify_xml.py` повторно проходит весь источник через SAX и сравнивает все поля пользователей, карт и операций по упорядоченным дайджестам. Проверяются типы ID, даты и внешние ключи. `verification.json` содержит итоги.

Старый плоский результат находится в `legacy/`: он смешивал 436 090 операций с 645 пустыми картами и терял пользователей без карт. Пример DS находится в `samples/` и не считается полным исходником. Актуальный интерфейс запуска — CLI выше; старый `recover=True` и преобразование uid в число удалены.
